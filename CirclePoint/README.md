# 点与圆的位置关系判断系统

## 项目简介
此项目主要目的是为了掌握**多文件编程**、**类的封装**以及**对象之间的组合关系**。

## 核心功能
通过输入一个圆心坐标、半径，以及一个点的坐标，计算该点是在圆内、圆上还是圆外。

## 项目文件结构
- `main.cpp`：程序入口，负责创建对象并调用逻辑。
- `Point.h` / `Point.cpp`：点类的声明与实现，包含 x、y 坐标的 setter 和 getter。
- `Circle.h` / `Circle.cpp`：圆类的声明与实现，包含圆心（Point 对象）和半径。

## 关键逻辑
本项目主要考察了类的组合（圆包含点）以及距离公式的应用：
`distance = sqrt((x1-x2)^2 + (y1-y2)^2)`
- 距离小于半径：点在圆内
- 距离等于半径：点在圆上
- 距离大于半径：点在圆外

## 开发环境
- 编程语言：C++
